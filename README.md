# V-Master

<p align="left">
  <b>🇺🇦 Українська</b> •
  <a href="README.en.md">🇬🇧 English</a>
</p>

**V-Master** — швидкий та зручний настільний клієнт для **macOS** та **Windows**, створений для моніторингу кластерів **Proxmox Virtual Environment** і щоденного адміністрування віртуальних машин та контейнерів на базі **Linux (Ubuntu / Debian)**.

Застосунок об'єднує всі ключові інструменти адміністратора в одному вікні: веб-API гіпервізора, SSH-термінал із підтримкою сесій та вкладок, двопанельний SFTP-менеджер, моніторинг Docker-контейнерів та безпечне оновлення системних пакунків.

---

## Що вміє V-Master

### 🖥️ Керування віртуальними машинами та контейнерами Proxmox VE
- **Підтримка KVM/QEMU та LXC**: повноцінне керування віртуальними машинами (`VM`) та легковими контейнерами (`CT`) з кольоровими бейджами для швидкого розрізнення.
- **Швидкі операції**: запуск, плавне вимкнення, примусова зупинка та перезавантаження однієї чи кількох ВМ одночасно через плаваючу панель масових дій.
- **Снапшоти**: створення миттєвих знімків стану (зі збереженням RAM чи без), швидкий відкат або видалення.
- **Керування бекапами (VZDump)**: перегляд наявних резервних копій та створення нових бекапів на обране сховище (режими *Snapshot*, *Suspend*, *Stop*; стиснення *ZSTD*, *GZIP* або без стиснення).
- **Інтерактивні графіки навантаження (RRD)**: наочні графіки використання процесора (CPU %) та оперативної пам'яті (RAM) за останні **1 годину**, **24 години** чи **7 днів** із підрахунком середнього навантаження, піків, актуальних значень, координатною шкалою, інтерактивним інспектором при наведенні та плавним перемиканням інтервалів без перезавантаження сторінки ВМ.
- **Моніторинг нод**: статус вузлів кластера, температура, пам'ять та керування службами Proxmox (`pve-cluster`, `pvedaemon`, `pveproxy`).

### ⚡ Глобальна командна палітра (Spotlight Command Palette)
- Викликається натисканням **`⌘ + K`** (або **`⌘ + P`**) на macOS та **`Ctrl + K`** / **`Ctrl + P`** на Windows.
- Миттєвий пошук будь-якої віртуальної машини за назвою або ID.
- Швидкий перехід до розділів застосунку або виконання дій живлення без блукання меню.

### 💻 Повноцінний SSH-термінал
- **Багатозадачність**: відкриття кількох сесій одночасно у зручних вкладках (**`⌘ + T`** / **`Ctrl + T`** — нова вкладка, **`⌘ + W`** / **`Ctrl + W`** — закрити).
- **Безпечне підключення**: автентифікація за паролем або SSH-ключами (`id_ed25519`, `id_rsa`), підтримка системного `ssh-agent` (macOS Keychain та Windows OpenSSH Agent).
- **SSH Bastion / Jump Host**: легке тунелювання з'єднань до закритих серверів через проміжний хост.
- **Auto-Reconnect**: автоматичний 5-секундний відлік та відновлення зв'язку при раптовому обриві мережі.
- **Збереження пароля sudo**: безпечне шифрування системного пароля, щоб не вводити його щоразу під час рутинних завдань.
- **Бібліотека сніппетів**: готові швидкі команди для діагностики дисків, пам'яті, мережі та пакетів в один клік.
- **Вибір тем та шрифтів**: палітри Dark, Light, Dracula, Monokai з налаштуванням розміру шрифту.

### 📁 Двопанельний SFTP-менеджер файлів
- Перегляд файлової системи сервера, завантаження та вивантаження файлів.
- Підтримка перетягування файлів (**Drag-and-Drop**) безпосередньо з робочого столу комп'ютера.
- Вбудований повноекранний текстовий редактор із підсвічуванням синтаксису та збереженням за комбінацією **`⌘ + S`** (**`Ctrl + S`**).
- Режим **Live Tail**: автоматичне оновлення перегляду лог-файлів у реальному часі.

### 🐳 Docker та системна діагностика
- **Моніторинг Docker**: перегляд списку запущених та зупинених контейнерів, їхніх портів та статусів.
- **Керування контейнерами**: швидкий перезапуск і перегляд живих логів обраного контейнера в окремому вікні.
- **Live Journalctl**: потокове читання системного журналу `journalctl` у реальному часі з фільтрацією за рівнем важливості (*Всі*, *Помилки*, *Увага*) та пошуком.
- **Процеси та ресурси**: перегляд процесів, що найбільше навантажують CPU/RAM, зупинка завислих процесів (`kill`) та очищення дискового кешу (`drop_caches`).

### 🛡️ Безпечне оновлення пакетів ОС (Safety Snapshots)
- Автоматичне створення захисного снапшота перед початком оновлення пакунків.
- Кнопка швидкого повернення назад (Rollback) в один клік, якщо оновлення спричинило збій.
- Розподіл оновлень на критичні (безпекові) та звичайні.

## Встановлення

### macOS
1. Перейдіть на сторінку релізів: 👉 **[Завантажити останню версію](https://github.com/MagnaMentes/v-master/releases/latest)**.
2. Завантажте архів `V-Master-X.X.X-arm64-mac.zip`.
3. Розпакуйте архів та перетягніть `V-Master.app` у теку **«Програми»** (`/Applications`).

> **Примітка для першого запуску на macOS:**  
> Додаток розповсюджується відкрито і безкоштовно без платного сертифіката Apple Developer, тому система безпеки Gatekeeper може показати повідомлення про невстановленого розробника.  
> 
> **Як відкрити:**
> - Натисніть правою кнопкою миші (або `Control + клік`) на `V-Master.app` у теці «Програми» і виберіть **«Відкрити»** -> підтвердіть запуск.  
> - Або зніміть атрибут карантину однією командою в Терміналі:
>   ```bash
>   xattr -c /Applications/V-Master.app
>   ```

### Windows
1. Завантажте файл встановлення для Windows зі сторінки **[Останнього релізу](https://github.com/MagnaMentes/v-master/releases/latest)**.
2. Запустіть інсталятор та дотримуйтесь вказівок на екрані (програма автоматично створить ярлик на Робочому столі).

## Збірка з вихідного коду (для розробників)

```bash
# Клонування репозиторію
git clone https://github.com/MagnaMentes/v-master.git
cd v-master

# Встановлення залежностей
npm install

# Запуск у режимі розробки
npm run dev

# Збірка інсталяційного пакету для macOS
npm run package

# Збірка інсталяційного пакету для Windows
npm run package:win
```
