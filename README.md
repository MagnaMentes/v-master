# V-Master

<p align="left">
  <b>🇺🇦 Українська</b> •
  <a href="README.en.md">🇬🇧 English</a>
</p>

**V-Master** — настільний клієнт для macOS (Apple Silicon), створений для централізованого моніторингу кластерів **Proxmox Virtual Environment** та щоденного адміністрування віртуальних машин на базі **Ubuntu / Debian Linux**.

Застосунок поєднує веб-API гіпервізора з повноцінним робочим середовищем системного адміністратора: інтегрованим терміналом, двопанельним SFTP-клієнтом, аналітикою процесів та інструментами безпечного пакетного оновлення системних компонентів.

---

## Основні можливості

- **Глобальна палітра швидких команд (Spotlight Command Palette)**:
  - Миттєвий виклик комбінаціями **`⌘ + K`** або **`⌘ + P`** з будь-якого екрана.
  - Швидка навігація між розділами («Дашборд», «Ноди», «SFTP», «Налаштування»).
  - Пошук та перехід до віртуальних машин за назвою або ID.
  - Швидке керування живленням (запуск, зупинка, перезавантаження), відкриття термінала та запуск поглибленої діагностики ВМ без зайвих кліків.

- **Багатозадачний SSH-термінал із підтримкою вкладок**:
  - Паралельна робота з кількома сесіями одночасно.
  - Гарячі клавіші для керування: **`⌘ + T`** (нова вкладка), **`⌘ + W`** (закрити вкладку), **`⌘ + 1..9`** (швидке перемикання між сесіями).
  - Візуальні бейджі активності та індикатори статусу з'єднання у реальному часі.
  - Швидке підключення до гостьових систем за збереженими профілями, інтеграція з системним `ssh-agent` macOS Keychain та підтримка SSH-ключів (`~/.ssh/id_rsa`, `id_ed25519`).
  - Бібліотека готових кастомних сніппетів для виконання частих адміністративних команд в один клік.

- **Керування кластерами та масові операції (Proxmox VE)**:
  - Моніторинг статусу серверів, навантаження CPU, RAM та сховищ у реальному часі.
  - Мультиселект ВМ чекбоксами з плаваючою панеллю дій (Floating Action Bar) для групового запуску, зупинки, перезавантаження та пакетного оновлення.
  - Перегляд та перезапуск системних служб ноди (`pve-cluster`, `pvedaemon`, `pveproxy` тощо).
  - Створення, відкат та видалення снапшотів з можливістю збереження стану RAM.

- **Безпечне оновлення пакунків із захисними снапшотами (Safety Snapshots)**:
  - Автоматичне створення контрольної точки відновлення (Safety Snapshot) перед встановленням оновлень.
  - Кнопка швидкого відкату (Rollback) в один клік у разі виникнення помилок після апдейту.
  - Розподіл оновлень на критичні (безпекові) та звичайні.
  - Пакетне встановлення в межах єдиної ізольованої сесії, що запобігає розривам зв'язку та блокуванням Fail2ban при оновленні мережевих компонентів (`libc-bin`, `sshd`).

- **Поглиблена системна діагностика та Live Journalctl**:
  - Інтерактивний переглядач системних журналів `journalctl` з фільтрами за рівнем важливості (*Всі*, *Помилки*, *Увага*), вибором служб (systemd unit: `ssh`, `nginx`, `docker`) та миттєвим пошуком за текстом.
  - Моніторинг топ-процесів за навантаженням на CPU та оперативну пам'ять у реальному часі.
  - Завершення завислих процесів (`kill`, `SIGKILL`), перезапуск служб `systemd` та очищення дискового кешу ядра ОС (`drop_caches`).

- **Двопанельний SFTP-менеджер із вбудованим редактором файлів**:
  - Зручна навігація віддаленою файловою системою сервера.
  - Завантаження, скачування, перейменування та безпечне видалення файлів і директорій.
  - Вбудований повноекранний редактор конфігураційних і текстових файлів із підрахунком рядків, підсвічуванням коду та швидким збереженням безпосередньо на сервер через **`⌘ + S`** (`Ctrl + S`).

- **Нативні системні сповіщення macOS**:
  - Інтеграція з macOS Notification Center для миттєвого інформування про непередбачену зупинку або аварійний збій ВМ (`running` -> `stopped`).
  - Оповіщення про успішне завершення тривалих фонових операцій оновлення.

- **Дизайн та автоматичні оновлення застосунку**:
  - Адаптивна тема (System / Dark / Light) із врахуванням матеріалів macOS Vibrancy.
  - Автоматична фонова перевірка свіжих релізів через GitHub із детальним модальним вікном «Що нового».

## Встановлення на macOS

### Системні вимоги
- macOS 12.0 (Monterey) або новіша.
- Архітектура: **Apple Silicon (M1 / M2 / M3 / M4)**.

### Інструкція зі встановлення

1. Перейдіть до останнього релізу:  
   👉 **[Завантажити V-Master](https://github.com/MagnaMentes/v-master/releases/latest)**

2. Завантажте архів `V-Master-X.X.X-arm64-mac.zip`.

3. Ропакуйте архів та перемістіть застосунок `V-Master.app` у теку **«Програми»** (`/Applications`).

> **Важливо для першого запуску:**  
> Проєкт розповсюджується відкрито без платного сертифіката Apple Developer ID, тому система macOS Gatekeeper може попередити про додаток від невстановленого розробника.  
> 
> Щоб відкрити програму:
> - Натисніть правою кнопкою миші (або `Control + клік`) на `V-Master.app` у теці «Програми» та оберіть пункт **«Відкрити»** (Open) -> підтвердіть запуск.  
> - Або виконайте команду в Терміналі для зняття карантинного атрибута:
>   ```bash
>   xattr -cr /Applications/V-Master.app
>   ```

## Безкоштовний статус та підтримка проєкту

**V-Master є повністю безкоштовним інструментом** із відкритим кодом. У ньому немає платної функціональності, прихованих підписок чи штучних обмежень на кількість серверів.

Застосунок розробляється та підтримується для вирішення реальних завдань системного адміністрування та зручної роботи з Homelab-інфраструктурою.

Якщо V-Master став вам у пригоді та допомагає економити час, ви можете підтримати розробку та розвиток нових функцій:

☕ **[Підтримати V-Master (Банка Monobank)](https://send.monobank.ua/jar/6s5yE12CxH)**

Зробити донат також можна безпосередньо з програми — натиснувши кнопку **«Підтримати V-Master»** у нижній частині бічного меню. Дякуємо за вашу підтримку!

## Збірка з вихідного коду (для розробників)

```bash
# Клонування репозиторію
git clone https://github.com/MagnaMentes/v-master.git
cd v-master

# Встановлення залежностей
npm install

# Запуск у режимі розробки
npm run dev

# Збірка під macOS (Apple Silicon)
npm run package
```
